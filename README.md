# Nom LokSewa

Nom LokSewa is an independent preparation platform for Nepal LokSewa Adhikrit aspirants.

## MVP
- Daily MCQ practice
- Instant explanations
- Local mistake notebook
- 90-day preparation roadmap
- PWA/service-worker foundation
- Responsive mobile-first interface
- Source-first architecture for current affairs

## Roadmap
AI tutor, official-source current affairs ingestion, syllabus/question-bank management, answer-writing evaluation, user accounts, analytics, subscriptions and institutional dashboards.

> Nom LokSewa is not an official Public Service Commission website.
